## インストールの仕方 / HowToUse
1. 各自zipファイルを選び、ダウンロードします。
2. Kritaを開き、「ツール」→「スクリプト」→「Pythonプラグインファイルからインポート」をクリック。
3. ファイルの選択画面から、ダウンロードしたzipファイルを選び開くをクックしてください。
4. 画面に従って、はいをクリックします。
5. Krita再起動します。
6. 設定でPythonプラグインマネージャーで該当のプラグインをクリックすれば、使用可能となります。

1. Choose plugin zip file and download.
2. Open Krita,and click Tools > Scripts > Import Python Plugin from File.
3. Choose plugin zip file you downloaded by step 1. and click Yes(or OK).
4. Restart Krita
5. Click Checkbox installed plugin by Python plugin manager.
